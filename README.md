# 🎯 BDJobs AI Matcher Mobile Web App

An on-demand job scraping and Gemini AI career matching application built with FastAPI and a modern, mobile-responsive Web UI.

## 🌟 Key Features

- **On-Demand Action**: Tap **"Fetch & Match Today's Jobs"** anytime to scrape fresh BDJobs listings and evaluate them against your CV using Gemini 2.5 Flash API.
- **Match Score & AI Reason**: See fit percentages (80%+ High Fit 🔥) along with Gemini's detailed reasoning.
- **Mobile Access**: Open `http://<YOUR_WI_FI_IP>:8000` on your smartphone browser while connected to the same Wi-Fi.
- **Manage CV**: Upload or swap PDF resumes directly from the UI.
- **Filters & Search**: Instantly search by title, company, or location, and filter by High/Medium match tiers.

## 🚀 Quick Start

1. Open your terminal in this directory (`bdjobs_matcher_app`).
2. Run the application:
   ```bash
   python start_app.py
   ```
3. Open `http://localhost:8000` in your computer browser, or open `http://<YOUR_IP>:8000` on your smartphone!
